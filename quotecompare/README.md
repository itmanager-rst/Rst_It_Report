# QuoteCompare

ระบบเปรียบเทียบราคาใบเสนอราคาตามใบขอซื้อ (Purchase Request) สำหรับ RST GROUP
สร้างเป็น [Google Apps Script](https://developers.google.com/apps-script) web app — ไม่มีระบบล็อกอิน เปิดลิงก์แล้วใช้งานได้ทันที

## ฟีเจอร์หลัก

- **อัปโหลดใบขอซื้อ (PR)** — PDF / รูปภาพ / Excel / CSV → ดึงรหัสสินค้า/ชื่อ/จำนวนมาตั้งต้นรายการอัตโนมัติด้วย Gemini AI
- **สร้างใบขอราคา (RFQ)** — ส่งออกเป็น PDF เพื่อส่งให้ supplier ขอราคากลับมา
- **อัปโหลดใบเสนอราคาจาก supplier** (2-4 ราย) — PDF / รูปภาพ / Excel / CSV → จับคู่รายการด้วยรหัสสินค้า/ชื่อสินค้าอัตโนมัติ
- **ตารางเปรียบเทียบราคา** พร้อมทำสัญลักษณ์ราคาที่ถูกที่สุด คำนวณ VAT และค่าจัดส่งให้อัตโนมัติ
- **พิมพ์ / ส่งออก PDF** ใบเปรียบเทียบราคา (A4 แนวนอน/แนวตั้ง, ปกติ/กะทัดรัด) พร้อมข้อเสนอแนะจาก AI และช่องลงนาม
- **ส่งออก Excel (.xlsx)** ทั้งใบขอราคาและใบเปรียบเทียบราคา
- ข้อมูลทั้งหมดเก็บในแท็บ **"RFQs"** ของ Google ชีตที่ผูกกับสคริปต์

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ — จัดการข้อมูลในชีต และเรียก Gemini API สำหรับอ่านไฟล์/สรุปข้อเสนอแนะ |
| `index.html` | หน้าเว็บแอปทั้งหมด (HTML/CSS/JS ฝั่งไคลเอนต์) |
| `appsscript.json` | ไฟล์ manifest ของโปรเจกต์ Apps Script |

## วิธีติดตั้ง

1. เปิด Google ชีตที่ต้องการใช้เก็บข้อมูล (หรือสร้างชีตใหม่)
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. คัดลอกเนื้อหาไฟล์ `Code.gs` ในรีโปนี้ไปวางแทนไฟล์ `Code.gs` เริ่มต้น
4. สร้างไฟล์ใหม่ชนิด **HTML** ชื่อ `index` (ต้องชื่อนี้เป๊ะๆ) แล้ววางเนื้อหาไฟล์ `index.html`
5. ตั้งค่า Gemini API key:
   - ขอฟรีได้ที่ [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
   - ในหน้า Apps Script: ไอคอนเฟือง **Project Settings** → เลื่อนลงไปที่ **Script Properties** → Add script property
   - Property: `GEMINI_API_KEY`   Value: `<คีย์ที่ได้มา>`
6. **Deploy → New deployment** → เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: เลือกตามที่ต้องการ (เช่น เฉพาะคนในองค์กร)
7. กด Deploy แล้วอนุญาตสิทธิ์การเข้าถึง (ครั้งแรกจะมีหน้าจอเตือนเพราะเป็นสคริปต์ที่ยังไม่ได้ยืนยันตัวตน — กด "Advanced" แล้วดำเนินการต่อได้) จะได้ลิงก์เว็บแอปรูปแบบ `https://script.google.com/macros/s/.../exec`

**ข้อควรระวัง**: ต้องเปิดใช้งานผ่านลิงก์ที่ได้จากขั้นตอน Deploy เท่านั้น ห้ามดาวน์โหลดไฟล์ `index.html` มาเปิดตรงๆ ในเบราว์เซอร์ เพราะ `google.script.run` ที่ใช้เชื่อมกับฐานข้อมูลจะไม่ทำงาน

## อัปเดตโค้ดหลังแก้ไข

ทุกครั้งที่แก้ `Code.gs` หรือ `index.html` แล้วอยากให้มีผลกับลิงก์เว็บแอปเดิม ต้องกด **Deploy → Manage deployments** → แก้ไข deployment เดิม → เลือก **Version: New version** → Deploy (แค่บันทึกไฟล์ในตัวแก้ไขอย่างเดียวจะยังไม่มีผลกับเว็บแอปที่ deploy ไปแล้ว)

## ข้อมูลที่จัดเก็บ

ระบบสร้างแท็บ `RFQs` ในสเปรดชีตที่ผูกกับสคริปต์โดยอัตโนมัติในการบันทึกครั้งแรก แต่ละแถวคือใบขอซื้อ 1 ใบ เก็บข้อมูลรายการสินค้าและใบเสนอราคาทั้งหมดเป็น JSON
