เพิ่มผู้ใช้งานใหม่

รายชื่อผู้ใช้งานทั้งหมด

• เจ้าหน้าที่จัดซื้อ: เลือกซื้อได้ แต่กดอนุมัติราคาไม่ได้ — ชื่อจะแสดงในเอกสารช่อง "ผู้จัดทำใบเปรียบเทียบราคา"

• ผู้จัดการ: อนุมัติราคาได้ — ชื่อจะแสดงในเอกสารช่อง "ผู้ตรวจสอบ/อนุมัติ" — เห็นรายชื่อผู้ใช้งานทั้งหมดและเพิ่มคนใหม่ได้

• เจ้าหน้าที่จัดซื้อจะไม่เห็นเมนูตั้งค่านี้ และเลือกได้เฉพาะชื่อระดับเจ้าหน้าที่ด้วยกันเท่านั้น

เชื่อมต่อ Google Sheet (ฐานข้อมูล)

บันทึกข้อมูลทุกครั้งที่มีการเปลี่ยนแปลง ไปเก็บไว้ใน Google Sheet ของคุณอัตโนมัติ

ยังไม่ได้เชื่อมต่อ
🎉 แอปนี้เปิดผ่านลิงก์ที่แชร์ (Apps Script Web App) จึงเชื่อมต่อฐานข้อมูลกลางให้อัตโนมัติแล้ว — ทุกคนที่เปิดลิงก์เดียวกันนี้จะเห็นและแก้ไขข้อมูลชุดเดียวกัน ไม่ต้องตั้งค่าอะไรเพิ่มเติม

📥 ดึง "สถานะใบขอซื้อ" อัตโนมัติจาก RST GROUP Data Hub

ระบบอ่านข้อมูลผ่าน Code.gs เวอร์ชัน 5 — ถ้าใช้ Code.gs เวอร์ชันเก่าอยู่ ให้คัดลอกโค้ดใหม่ไปวางแล้ว Deploy → Manage deployments → ✏️ → Version: New version

ขั้นตอนตั้งค่า (ทำครั้งเดียว)

  1. เปิด Google Sheet ที่ต้องการใช้เก็บข้อมูล (สร้างไฟล์ใหม่ก็ได้)
  2. เมนู ส่วนขยาย (Extensions) → Apps Script
  3. ไฟล์ Code.gs: ลบโค้ดเดิมทั้งหมด แล้วคัดลอกโค้ดด้านล่างไปวาง แล้วกด บันทึก
  4. กด "+" ข้าง Files → HTML ตั้งชื่อไฟล์ว่า Index (ตัว I ใหญ่) ลบโค้ดเดิมในไฟล์นั้น แล้วเปิดไฟล์แอปนี้ (เปรียบเทียบราคา.html) ด้วยโปรแกรมแก้ไขข้อความ คัดลอกเนื้อหาทั้งหมดไปวางในไฟล์ Index ที่สร้าง — นี่คือขั้นตอนที่ทำให้เปิดลิงก์แล้วเห็นแอปทั้งหน้าเลย
  5. กด Deploy → New deployment → เลือกประเภท "Web app" ตั้งค่า Execute as: Me, Who has access: Anyone แล้วกด Deploy (ครั้งแรกต้อง Authorize สิทธิ์)
  6. คัดลอก URL ที่ได้ — นี่คือลิงก์เดียวที่แจกให้ทุกคนเปิดใช้งานได้เลย ไม่ต้องตั้งค่าฝั่งผู้ใช้งานเพิ่ม

💡 หรือถ้าแค่อยากซิงค์ข้อมูลจากไฟล์ที่เปิดในเครื่องตัวเอง (ไม่ต้องแจกลิงก์ให้ใคร) ให้ทำแค่ขั้นตอน 1-3 และ 5-6 (ข้าม 4) แล้ววาง URL ที่ได้ในช่องด้านล่าง
