    📋 วางข้อมูลค่าใช้จ่าย (ประวัติการชำระเงิน) จากหน้า Bluehost
    1. เข้า Bluehost → Billing → รายการคำสั่งซื้อ (ตารางที่มีคอลัมน์ Date · Order Number · Payment Method · Total)
    2. ลากคลุมตารางทั้งหมด แล้วกด Ctrl + C (คัดลอกหัวตาราง/ปุ่ม Filters, View Receipt มาด้วยได้ ระบบจะข้ามให้)
    3. วางในช่องด้านล่าง → กด “ตรวจสอบข้อความ” → ตรวจยอด แล้วกด “นำเข้าข้อมูล” (วางซ้ำได้ ระบบตัดรายการซ้ำด้วย Order Number)
    วันต่ออายุ / Auto-renew: กด 📤 อัปโหลดไฟล์ Renewal Center (Bluehost → Renewal Center → Export .csv) · ราคาต่อรอบของแต่ละบริการใส่ได้ด้วยปุ่ม ✏️ ในตารางรายการบริการ
