ตั้งค่าระบบ (Admin)

เพิ่ม/แก้ไข/ลบรายการด้านล่าง มีผลกับทุกโมดูลและรายงานที่เกี่ยวข้องทันที (แบบฟอร์มบันทึกข้อมูล, ตาราง Recent Entries, กราฟและ Dashboard ทั้งหมด)
หมายเหตุ: หน้านี้เป็นระดับการมองเห็นเมนู/ปุ่มในหน้าเว็บเท่านั้น (client-side) ไม่ใช่ระบบความปลอดภัยจริง เนื่องจากไฟล์นี้ไม่มี server - ผู้ใดก็ตามที่เปิดไฟล์สามารถแก้ไขข้อมูลผ่าน source code ได้
เว้นช่อง EN/VN ว่างไว้ได้ - ระบบจะแปลจากภาษาไทยให้อัตโนมัติเมื่อกดบันทึก (ต้องมีอินเทอร์เน็ต)

เชื่อมต่อฐานข้อมูล Google Sheets

วาง Web App URL จาก Google Apps Script ที่นี่ เพื่อให้ข้อมูลทุกโมดูล (Defect, Breakdown, Performance, Performance Test) และการตั้งค่า (ประเภท Defect/สาเหตุ, รายชื่อ Admin/ผู้บันทึก) เก็บและใช้ร่วมกันผ่าน Google Sheets แทนที่จะเก็บแยกในแต่ละเครื่อง - ดูขั้นตอนตั้งค่าในไฟล์ GoogleAppsScript_Code.gs ที่แนบมาด้วย
หมายเหตุ: รูปภาพ Defect ยังคงเก็บเฉพาะในเครื่องที่ถ่าย/แนบไฟล์เท่านั้น (ไม่ซิงค์ขึ้น Google Sheets เนื่องจากข้อจำกัดขนาดเซลล์)
