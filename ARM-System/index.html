  1. พิมพ์คำค้นในช่องค้นหา ค้นได้ทุกคอลัมน์ หลายคำเว้นวรรค เช่น รถขุด 2569, EF393T อุบล, เลขที่ใบขาย, หมายเลขเครื่อง
  2. คลิกหัวคอลัมน์เพื่อเรียงลำดับ · ปุ่ม เลือกคอลัมน์ = กำหนดคอลัมน์ที่แสดงและที่จะพิมพ์
  3. ติ๊กรายการที่ต้องการ หรือ “เลือกทั้งหมด (ตามผลค้นหา)” → กด พิมพ์ / บันทึก PDF ที่แถบด้านล่าง
  4. ตั้งหัวเรื่อง หมายเหตุ (เช่น “แฟ้มที่ 3 · พ.ย. 2569”) แถวรวมยอด ช่องลงชื่อ เว้นขอบเจาะแฟ้ม
  5. หน้าต่างพิมพ์ของ Chrome: ปลายทาง บันทึกเป็น PDF (หรือเลือกเครื่องพิมพ์) · ขนาด A4 · แนวนอน ตั้งให้อัตโนมัติ
