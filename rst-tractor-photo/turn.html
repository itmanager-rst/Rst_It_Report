    #ทะเบียนรถหมายเลขรถ / เครื่องรับเข้าชื่อ-สกุลเอกสารสถานะEcount
    ไม่พบรายการตามเงื่อนไข

    นำเข้าจาก Excel เฉพาะ admin

    รองรับไฟล์ "รายการรถตีเทิร์น" รูปแบบเดิม (ชีต รถตีเทิร์น และ รถตีเทิร์น กทบ.) ระบบหาแถวหัวตารางเอง วันที่ พ.ศ. แปลงให้อัตโนมัติ

    ส่งออก

    ดาวน์โหลดข้อมูลทั้งหมดเป็น Excel (หัวคอลัมน์ภาษาไทย วันที่เป็น พ.ศ.) พร้อมคอลัมน์ข้อมูลจาก Ecount

    เกี่ยวกับข้อมูล

    • เก็บในชีต TurnCars ของไฟล์ Google Sheet เดียวกับแอปรูปรถ
    • ทุกการเพิ่ม/แก้/ลบ บันทึกในชีต TurnLog (รายการที่ลบกู้คืนได้จากหน้าความเคลื่อนไหว)
    • นำเข้าแบบ "แทนที่ทั้งหมด" จะสำรองชีตเดิมเป็น TurnCars_backup_วันเวลา ก่อน
    • ผู้ใช้ CRM ทุกคนดูได้ · เพิ่ม/แก้ไข ต้องใช้ PIN ทีม (admin ไม่ต้อง) · ลบ / กู้คืน / นำเข้า เฉพาะ admin

    เพิ่มรถตีเทิร์น

    ซ่อนข้อมูลชั่วคราวรายการรถตีเทิร์นมีข้อมูลส่วนบุคคลของลูกค้า เป็นความลับของบริษัท
    ห้ามแคปหน้าจอหรือถ่ายรูปส่งต่อ · ทุกการเข้าใช้งานถูกบันทึก
